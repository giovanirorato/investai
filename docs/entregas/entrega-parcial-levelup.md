# Entrega Parcial LevelUp

## Prazo

`27/04/2026`

## Objetivo do documento

Este arquivo organiza os requisitos da entrega parcial em formato de checklist, para facilitar planejamento, acompanhamento e distribuicao das atividades.

## 1. Definicao do Problema e Personas "IA-Augmented" (2,0 pts)

### Entregaveis principais

- [ ] Descrever o problema em ate 250 caracteres.
- [ ] Descrever a solucao em ate 250 caracteres.
- [ ] Explicar explicitamente onde a IA gera valor: automacao, predicao ou geracao de conteudo.
- [ ] Definir as personas do produto.

### Cenarios de uso e casos de borda

- [ ] Mapear cenarios principais de uso.
- [ ] Identificar falhas possiveis e casos criticos de erro relacionados ao uso de IA.

### Entrevistas e validacao

- [ ] Registrar entrevistas com humanos.
- [ ] Registrar entrevistas com agentes inteligentes.
- [ ] Consolidar pontos de dor levantados.
- [ ] Validar se o problema faz sentido para o publico-alvo.

## 2. Backlog e Engenharia de Requisitos "AI-First" (2,0 pts)

### Backlog priorizado

- [ ] Definir epicos.
- [ ] Escrever historias de usuario.
- [ ] Detalhar tarefas derivadas de cada historia.
- [ ] Documentar padroes de uso de ferramentas de IA no projeto.

### Criterios de aceite

- [ ] Definir criterios de aceitacao claros para cada historia.
- [ ] Explicar como validar se os resultados das ferramentas de IA estao corretos.

## 3. Banco de Dados e API (2,0 pts)

### Modelo de dados

- [ ] Representar entidades, atributos e relacionamentos.
- [ ] Identificar chaves primarias e estrangeiras.
- [ ] Destacar quais entidades se relacionam diretamente ao uso de IA, quando aplicavel.

### Design da API

- [ ] Definir principais endpoints.
- [ ] Informar metodos HTTP.
- [ ] Documentar estrutura de requisicoes e respostas.

### Fluxo de dados e logica do sistema

- [ ] Descrever entrada de dados.
- [ ] Descrever processamento classico.
- [ ] Explicar integracao com servicos de IA.
- [ ] Explicar estrategias de indexacao e recuperacao de dados para IA.
- [ ] Documentar persistencia dos dados.
- [ ] Explicar retorno para o frontend.
- [ ] Incluir pelo menos um exemplo de fluxo completo.

### Tratamento de excecoes e falhas

- [ ] Tratar erros de validacao, formato e valores ausentes ou invalidos.
- [ ] Tratar falhas de integracao com APIs externas.
- [ ] Tratar falhas em servicos de IA, como respostas inconsistentes ou incompletas.
- [ ] Considerar limites de requisicao, latencia e indisponibilidade.

## 4. Arquitetura de Software e Stack de Desenvolvimento (2,0 pts)

### Stack

- [ ] Definir stack de desenvolvimento.
- [ ] Informar ferramentas de IA utilizadas.
- [ ] Diferenciar ferramentas pagas e gratuitas.

### Arquitetura

- [ ] Documentar a estrutura de pastas do projeto.
- [ ] Desenhar a arquitetura da solucao.
- [ ] Explicar a integracao do backend com servicos de IA.
- [ ] Explicar como tratar latencia, erros, timeout e indisponibilidade.

## 5. Relato do Processo e Engenharia de Prompt (2,0 pts)

### Prompt Ops

- [ ] Manter repositorio de prompts com objetivo, contexto, saida esperada e problemas encontrados.

### Relato do processo

- [ ] Descrever o que foi feito ate o momento.
- [ ] Explicar como o time trabalhou.
- [ ] Relatar o impacto das ferramentas de IA no processo.
- [ ] Registrar aprendizados, dificuldades e ajustes feitos para garantir qualidade.
